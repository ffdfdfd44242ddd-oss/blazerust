О сервере //

Правила //

Играя на сервере, ты автоматически соглашаешься с правилами. Незнание правил не освобождает от ответственности.

1. Общие правила

  • Запрещено использование читов, макросов и стороннего ПО, дающего преимущество.
  • Запрещена эксплуатация багов сервера. Найденный баг — сразу сообщи администрации.
  • Запрещено оскорбление игроков и администрации, спам, флуд, реклама.
  • Запрещено выдавать себя за администрацию сервера.
  • Запрещена продажа игровых ценностей за реальные деньги (RMT).
  • Аккаунты с VAC-баном могут быть ограничены в игре.

2. Игровой процесс

  • Запрещён абуз привилегий и возможностей плагинов.
  • Запрещено гриферство намеренное (рейд-базы с оффлайн-таймером — по ситуации, решает админ).
  • Запрещено блокировать спавн, точки возрождения и ключевые объекты.
  • Запрещено строить в зонах событий с целью помешать их проведению.
Важно: решение администрации по спорным ситуациям является окончательным. Спорь спокойно и аргументированно — адекватные вопросы всегда рассматриваются.

Донат //

Донат — поддержка сервера. Все собранные средства идут на оплату хостинга и развитие проекта. Привилегии не дают неуязвимости и не заменяют навык игры.

VIP
Кит VIP, приоритетная очередь, цветной ник.
PREMIUM
Всё из VIP + расширенный кит, личные варпы.
LEGEND
Всё из PREMIUM + макси-кит, особый префикс, приоритет в тикетах.
Цены и условия покупки уточняй у администрации в телеграм-канале. Прайс может меняться.
Внимание: донат — добровольное пожертвование. Возврат средств не производится, если привилегия не была использована с нарушениями правил.

Жалобы //

Жалоба подаётся на игрока или администратора. Рассматриваются только корректно оформленные жалобы.

Как подать жалобу

  1. Сделай скриншот или запиши видео нарушения.
  2. Укажи ник нарушителя и время (примерно).
  3. Отправь всё в чат или на почту администрации.
  4. Дождись ответа. Обычно — в течение 24 часов.
Жалобы без доказательств не рассматриваются. Если жалоба ложная — заявитель сам получает наказание.

Кланы //

На сервере включена полноценная система кланов. Лимитов на количество участников нет (NOLIMIT).

  • /clan create Название — создать клан
  • /clan invite Ник — пригласить игрока
  • /clan accept — принять приглашение
  • /clan leave — покинуть клан
  • /clan info — информация о клане
  • /clan tag — установить тег клана
Внутриклановые разборки решаются внутри клана. Администрация не возвращает вещи, украденные союзниками по клану.

SteamID //

SteamID нужен для подачи жалоб, получения привилегий и восстановления вещей.

Как узнать свой SteamID

  1. Открой свой профиль Steam (в браузере, не в клиенте).
  2. Посмотри ссылку профиля — в конце будет 7656119... (это и есть SteamID64).
  3. Если ссылка вида /id/никинейм — скопируй ник, а ID найди на сайте типа steamid.io.
Не путай SteamID с никнеймом. По одному нику мы не сможем найти тебя в списках — ники можно менять.

Подключение //

Способ 1 — через кнопку

Нажми Подключиться — игра запустится и подключится сама.

Способ 2 — вручную через консоль

  1. Запусти Rust, открой консоль (клавиша F1).
  2. Введи команду: connect 46.174.48.219:28015
  3. Нажми Enter и жди загрузки.

Способ 3 — через браузер

Используй ссылку: steam://connect/46.174.48.219:28015 — вставь её в адресную строку браузера.

Сервер виден в списке серверов: закладка «Избранное» → «Добавить сервер» → введи IP и порт.
